# Практическая работа №6

## Тема

Основы ООП в JavaScript: классы, экземпляры и наследование.

## Запуск тестов

```bash
node tests.js
```

## Что нужно заполнить

Откройте `student-template.js` и заполните участки `TODO`.

Не изменяйте:

- имена классов и функции-конструктора;
- названия методов;
- список параметров;
- блок `module.exports` в конце файла.

В работе используются `class`, `constructor`, `new`, методы экземпляров, `this`, изменение состояния объекта, `extends`, `super()` и один пример старого подхода через функцию-конструктор и `prototype`.

Полные условия и примеры находятся в документе `Практическая_работа_6.docx`.

## Сдача

Для этой работы отдельная загрузка в учебную систему не требуется. Работа размещается и выполняется в вашем GitHub-репозитории в привычном формате.

В репозитории должны находиться:

- заполненный `student-template.js`;
- при необходимости краткий README с инструкцией запуска;
- при выполнении дополнительного браузерного упражнения - соответствующий JS-файл.

Перед завершением обязательно выполните:

```bash
node tests.js
```

Все шесть групп тестов должны завершиться успешно.
